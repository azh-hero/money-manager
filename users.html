User Setting

Kelola akun pengguna dan hak aksesnya.

Nama Email Username Password Role Status Aksi

Aturan hak akses

·  Pengguna biasa — hanya bisa menggunakan fitur User (catat transaksi).

·  Admin — seluruh fungsi pengguna biasa + akses Dashboard. Di halaman ini hanya bisa melihat.

·  Superadmin — seluruh fungsi Admin + tambah, ubah, dan hapus user.

·  User nonaktif — hanya bisa melihat sesuai rolenya, tidak bisa menyimpan atau mengubah data.

Tambah user

Buat akun baru dan tentukan rolenya.

opsional

Email tidak wajib diisi. Bila diisi, email tersebut bisa dipakai untuk login selain username.
